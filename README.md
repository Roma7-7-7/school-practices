# School Practices

Interactive learning exercises (starting with math), built for practice on an iPad or laptop,
hosted via GitHub Pages. UI is in Ukrainian; code and docs are in English.

Live site: enable GitHub Pages for this repo (Settings → Pages → Deploy from branch `main` / root)
and it'll be served at `https://<user>.github.io/school-practices/`.

See [CLAUDE.md](CLAUDE.md) for project conventions and how to add a new activity.
